재산세 납부 기간과 카드 혜택을 미리 알아두면 가산금 없이, 심지어 포인트나 캐시백까지 챙길 수 있습니다. 저도 처음엔 고지서를 받고 나서야 허둥지둥 납부했는데, 막상 카드사 혜택을 찾아보니 꽤 쏠쏠하더라고요. 이 글에서는 **2025년 기준 재산세 납부 기간**, 분납 조건, 절약 방법, 주요 카드사 혜택까지 한 번에 정리해 드립니다.

---

## 재산세란? 누가 얼마나 내야 할까

재산세는 매년 6월 1일 기준으로 토지·건축물·주택·선박·항공기를 소유한 사람에게 부과되는 지방세입니다. **6월 1일 현재 등기부상 소유자**가 납세의무자가 되므로, 부동산 매매 시 잔금일·소유권 이전일이 6월 1일 이전이냐 이후냐에 따라 납세 의무가 달라집니다.

| 과세 대상 | 과세 기준일 | 납부 시기 |
|---|---|---|
| 주택(1/2) | 6월 1일 | 7월 16일 ~ 7월 31일 |
| 주택(나머지 1/2) | 6월 1일 | 9월 16일 ~ 9월 30일 |
| 건축물 | 6월 1일 | 7월 16일 ~ 7월 31일 |
| 토지 | 6월 1일 | 9월 16일 ~ 9월 30일 |
| 선박·항공기 | 6월 1일 | 7월 16일 ~ 7월 31일 |

> **단, 주택분 산출세액이 20만 원 이하**이면 7월에 한꺼번에 납부합니다(9월 고지 없음).

세율은 주택 공시가격 기준 **0.1%~0.4%** 수준이며, 공정시장가액비율(2025년 기준 주택 60%)을 적용한 과세표준에 세율을 곱해 산출합니다. 정확한 세율 구조는 [행정안전부 지방세 안내](https://www.mois.go.kr/frt/a01/frtMain.do)에서 확인하세요.

## 재산세 납부 방법 — 온라인이 제일 편하더라

재산세는 오프라인(은행·구청)보다 온라인 납부가 훨씬 간편합니다. 저는 매번 위택스 앱으로 처리하는데, 공인인증서 없이 간편인증으로도 되니까 정말 편해요.

1. **위택스(Wetax)** : [www.wetax.go.kr](https://www.wetax.go.kr) 접속 → 로그인 → 납부하기 → 고지 내역 확인 후 카드·계좌이체로 결제
2. **스마트 위택스 앱** : 모바일에서 QR코드 또는 전자고지 연동 납부
3. **인터넷뱅킹·모바일뱅킹** : 각 은행 앱 → 지방세 납부 메뉴
4. **ARS(1599-3900)** : 24시간 전화 자동응답 납부
5. **편의점·은행 ATM** : 고지서 바코드 스캔 납부
6. **구청·시청 방문** : 직접 창구 납부

> **납부 기한 다음 날부터 가산금 3%** 가 자동 부과됩니다(지방세징수법 제30조 기준). 소액이라도 기한을 꼭 지키세요.

## 카드 혜택으로 재산세 절약하는 법

**카드사별 무이자 할부·포인트 환급 혜택을 잘 활용하면 실질 납부액을 줄일 수 있습니다.** 매년 7~9월 납부 시즌에 맞춰 카드사들이 프로모션을 진행하므로, 납부 전에 카드사 공식 앱·홈페이지에서 이벤트를 꼭 확인하세요.

| 카드사 | 대표 혜택 유형 | 비고 |
|---|---|---|
| 신한카드 | 2·3개월 무이자 할부, 마이신한포인트 적립 | 위택스 연동 할부 가능 |
| KB국민카드 | 무이자 할부(2~3개월), KB Pay 결제 시 캐시백 | 카드사 이벤트 페이지 확인 필요 |
| 삼성카드 | 삼성페이 결제 시 포인트 적립 | 기간 한정 |
| 현대카드 | M포인트 사용 납부, 무이자 할부 | M포인트로 세금 직납 가능 |
| 롯데카드 | 롯데포인트 사용 납부 | L.pay 연동 |
| 하나카드 | 무이자 할부, 하나머니 적립 | 이벤트 기간 한정 |
| 우리카드 | 위비페이 캐시백 | 기간·금액 제한 있음 |

> ⚠️ 카드 혜택은 **연도·카드 상품·이벤트 기간**에 따라 달라집니다. 납부 전 해당 카드사 공식 홈페이지 또는 고객센터에서 반드시 최신 혜택을 확인하세요.

**간편결제 캐시백**도 놓치지 마세요. 네이버페이·카카오페이·토스페이 등 간편결제 플랫폼이 지방세 납부 이벤트를 진행하는 경우가 있어 **최대 1~2% 캐시백**을 받을 수 있습니다.

## 재산세 분납 — 세금이 부담스럽다면 이렇게

재산세 고지액이 한 번에 내기 부담스러울 때는 **분납 제도**를 이용할 수 있습니다.

- **분납 요건** : 납부할 세액(재산세 + 도시지역분 합산)이 **250만 원 초과** 시 신청 가능
- **분납 방법** : 납부 기한 내 50%를 먼저 납부하고, 나머지 50%는 납부기한으로부터 **2개월 이내** 납부
- **신청 방법** : 위택스 또는 관할 시·군·구청에 납부기한 전 신청

분납은 이자(연체료)가 없으니 자금 여유가 부족할 때 적극 활용할 만합니다. 다만 분납 신청 없이 기한을 넘기면 가산금이 붙으므로 반드시 **기한 내 분납 신청**이 먼저입니다.

## 재산세 절약 꿀팁 체크리스트

**납부 전 아래 항목을 점검하면 불필요한 지출을 줄일 수 있습니다.**

- [ ] **6월 1일 기준 소유 여부 확인** : 매매 잔금일을 하루만 조정해도 납세의무자가 바뀔 수 있음
- [ ] **공시가격 이의신청 여부 검토** : 공시가격이 시세 대비 과다하다면 [부동산공시가격 알리미](https://www.realtyprice.kr)에서 이의신청 가능(매년 4~5월)
- [ ] **카드사 이벤트 사전 체크** : 납부 전 카드사 앱·홈페이지에서 무이자 할부·캐시백 이벤트 확인
- [ ] **간편결제 캐시백 비교** : 네이버페이·카카오페이·토스 중 혜택 큰 곳 선택
- [ ] **분납 조건 해당 여부 확인** : 세액 250만 원 초과 시 분납 신청 검토
- [ ] **전자고지 신청** : 위택스 전자고지 신청 시 세액 공제 혜택(연도별 상이, 시·군·구 정책에 따름) 가능한 경우 있음
- [ ] **납부 기한 달력 등록** : 7월 31일·9월 30일을 스마트폰 캘린더에 등록해 가산금 방지

> 재산세 제도 및 혜택은 지방자치단체 정책에 따라 변경될 수 있으니, 납부 전 **[위택스 공식 홈페이지](https://www.wetax.go.kr)** 또는 관할 구청에서 최신 정보를 확인하시길 권장합니다.
