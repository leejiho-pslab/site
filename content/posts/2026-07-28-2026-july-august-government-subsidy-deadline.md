막상 여러 지원금을 찾아보면 마감일이 제각각이라 헷갈리기 쉬운데, 아래 표 하나로 먼저 전체 그림을 잡아두면 훨씬 수월합니다.

## 근로장려금 반기 신청 — 8월 31일이 진짜 마감입니다

근로장려금 반기 신청은 2026년 상반기(1~6월) 소득을 기준으로 8월 한 달 동안만 신청할 수 있는, 연 1회 정기 신청과는 별개의 제도입니다.

저도 처음엔 "어차피 정기분으로 받으면 되지"라고 생각했는데, 반기 신청을 하면 **지급 시점이 12월로 당겨지고** 전체 수령액도 조금 더 유리할 수 있습니다. 반면 신청을 안 하면 내년 9월에야 정기분으로 받게 됩니다.

**신청 자격 요건 (2026년 기준, 국세청)**

| 구분 | 단독 가구 | 홑벌이 가구 | 맞벌이 가구 |
|---|---|---|---|
| 소득 기준 | 2,200만 원 미만 | 3,200만 원 미만 | 3,800만 원 미만 |
| 최대 지원액 | 165만 원 | 285만 원 | 330만 원 |
| 재산 기준 | 2억 4천만 원 미만 (공통) | | |

**신청 방법:**
1. [국세청 홈택스](https://www.hometax.go.kr) 접속 → 로그인
2. 상단 메뉴 '장려금·연말정산·전자기부금' 클릭
3. '근로장려금 반기신청' 선택 후 소득 정보 확인
4. 계좌번호 입력 → 제출

**흔한 실수:** 사업 소득이 있는 프리랜서는 '사업장 정보'를 꼼꼼히 입력해야 반려되지 않습니다. 모바일 앱(손택스)에서도 동일하게 신청 가능합니다.

## 에너지바우처 — 여름철 냉방비 지원, 8월 말까지만 받을 수 있어요

에너지바우처 여름 지원은 취약계층의 냉방비를 직접 지원하는 제도로, 2026년 여름 신청 마감은 **8월 31일**입니다.

실제로 주변에서 이 바우처를 몰라서 못 받는 분들을 꽤 봤는데요. 신청하면 전기요금 고지서에서 자동 차감되는 방식이라 한번 등록해 두면 편리합니다.

**지원 대상 (2026년 기준, 한국에너지공단)**

- 국민기초생활수급자(생계·의료·주거·교육급여) 가구
- 차상위계층 가구
- 위 요건 충족 + 노인(65세 이상), 영유아(6세 미만), 장애인, 임산부, 중증질환자·희귀질환자 포함 가구 → **가산 지원**

| 가구 유형 | 여름 지원 금액(전기) |
|---|---|
| 기본 지원 | 약 117,000원 |
| 취약계층 가산 | 약 184,900원 추가 |
| **최대 합산** | **약 302,000원** |

**신청 방법:**
1. 주민센터(읍·면·동) 방문 신청 (대리인 가능)
2. 또는 [복지로](https://www.bokjiro.go.kr) 온라인 신청
3. 신분증, 통장 사본, 수급자 확인서 지참

> 2026년 수치는 한국에너지공단 공식 안내 기준이며, 가구 구성에 따라 달라질 수 있습니다.

## 청년도약계좌 — 매월 모집, 7·8월 각각 별도 신청해야 합니다

청년도약계좌는 정부가 월 최대 **6만 원의 기여금**을 5년간 지원하는 청년 자산 형성 상품으로, 2026년에도 매월 신청 창구가 열리고 닫힙니다.

"나중에 가입하지 뭐"라고 미루다가 한 달 창구를 놓치면 그달 기여금을 영영 못 받게 됩니다. 한 달 6만 원이 5년이면 **최대 360만 원**인데, 아깝잖아요.

**자격 요건 (2026년 기준, 금융위원회)**

| 항목 | 기준 |
|---|---|
| 나이 | 만 19~34세 (병역 이행 기간 최대 6년 추가 인정) |
| 개인 소득 | 연 7,500만 원 이하 |
| 가구 소득 | 중위소득 250% 이하 |
| 금융소득 | 종합과세 해당자 제외 |

- **7월 신청 창구:** 통상 7월 초~중순 (각 은행 앱 공지 확인 필수)
- **8월 신청 창구:** 통상 8월 초~중순

**가입 방법:**
1. 취급 은행 앱(국민·신한·하나·우리·농협·기업·부산·경남·광주·전북은행 등) 실행
2. '청년도약계좌' 검색 → 신청 기간 내 신청
3. 소득 확인 서류 제출 (비대면 자동 연계)
4. 심사 후 개설 완료

## 소상공인 전기요금 특별지원 — 7월 31일, 정말 얼마 안 남았습니다

소상공인 전기요금 특별지원은 고물가·고금리 부담을 겪는 소상공인에게 전기요금 일부를 직접 지원하는 제도로, **2026년 신청 마감이 7월 31일**로 임박해 있습니다.

이 지원금은 신청 안 하면 그냥 없어집니다. 매출액 기준이 생각보다 넉넉하게 설정돼 있으니, "나는 해당 안 되겠지" 하고 넘어가지 말고 꼭 조회해 보세요.

**지원 대상 및 금액:**

| 구분 | 내용 |
|---|---|
| 대상 | 사업자등록 소상공인 (연 매출 3억 원 이하) |
| 지원 금액 | 최대 **20만 원** (전기요금 차감 방식) |
| 신청처 | [소상공인 포털](https://www.sbiz.or.kr) / 소상공인시장진흥공단 |
| 마감 | **2026년 7월 31일** |

**신청 방법:**
1. 소상공인 포털 로그인 (공동인증서 필요)
2. '전기요금 특별지원' 메뉴 클릭
3. 사업자등록번호·한전 고객번호 입력
4. 신청 완료 후 한전 고지서에서 자동 차감

## 국민취업지원제도 — 상시 신청이지만 조기 마감 주의

국민취업지원제도는 취업이 어려운 구직자에게 **월 50만 원씩 최대 6개월(총 300만 원)** 구직촉진수당과 취업 지원 서비스를 제공하는 제도입니다.

'상시 신청'이라고 해서 여유 부리다가 7~8월 예산이 소진되면 그해 신청이 어려워질 수 있습니다. 막상 알아보니 서류 준비부터 첫 수당 지급까지 1~2개월이 걸리기도 해서, 지금 당장 신청하는 게 유리합니다.

**자격 요건 (1유형 기준, 2026년 고용노동부)**

| 항목 | 기준 |
|---|---|
| 연령 | 15~69세 |
| 소득 | 가구 중위소득 60% 이하 |
| 재산 | 4억 원 이하 |
| 취업 경험 | 최근 2년 내 100일 또는 800시간 미만 |

**신청 방법:**
1. [고용24](https://www.work24.go.kr) 접속 → 회원가입·로그인
2. '국민취업지원제도' 신청 클릭
3. 가구원 소득·재산 입력 및 서류 업로드
4. 고용센터 상담 예약 후 방문
5. 개인 취업활동계획(IAP) 수립 → 수당 지급 시작

## 신청 전 꼭 알아야 할 실수 방지 체크리스트

이 섹션에서는 직접 신청해 보면서 또는 주변 사례에서 발견한 가장 흔한 실수와 주의사항을 정리합니다.

아무리 자격이 되어도 서류 하나 빠지면 반려되고, 마감일을 당일에 알면 시스템이 폭주해서 접속이 안 되는 경우도 있습니다. 아래 체크리스트를 미리 확인하세요.

**✅ 신청 전 필수 체크리스트**

- [ ] 본인 자격 여부 → [복지로 복지서비스 모의계산](https://www.bokjiro.go.kr)에서 먼저 조회
- [ ] 공동인증서(구 공인인증서) 또는 금융인증서 유효기간 확인
- [ ] 가구원 소득·재산 정보 (건강보험료 납부확인서, 금융정보 동의)
- [ ] 계좌번호는 본인 명의 통장으로 준비
- [ ] 마감일 2~3일 전에 신청 (마감 당일 서버 지연 위험)
- [ ] 신청 후 문자·이메일 수신 여부 설정 확인
- [ ] 지원금 수령 후 소득 변동 시 반드시 신고 (과오지급 환수 주의)

> 제도별 세부 요건과 지원 금액은 정책 변경에 따라 달라질 수 있습니다. [정부24](https://www.gov.kr) 및 각 부처 공식 누리집에서 반드시 최신 정보를 확인하시기 바랍니다.
